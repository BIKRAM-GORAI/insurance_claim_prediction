Pipeline Workflow

From raw data to
instant prediction

A transparent, reproducible 5-step machine learning pipeline.

01

Data Ingestion & Audit

Load 5,000 cleaned records with 40 columns. Verify zero nulls, validate category levels, and confirm target distribution (60.84% Approved / 39.16% Rejected).

02

Grouped Train/Holdout Split

Deterministic 80/20 grouped split on source_profile_id (seed 42). 792 train groups (4,005 rows), 197 holdout groups (995 rows). Zero overlap guaranteed.

03

Preprocessing Pipeline

ColumnTransformer with StandardScaler for 6 numeric features and OneHotEncoder for 3 categorical features. Packaged inside a single scikit-learn Pipeline — no separate artifacts.

04

Model Training & Selection

5-fold GroupKFold cross-validation across 4 classifiers. Dynamic selection based on holdout accuracy, macro F1, ROC-AUC, and confusion matrix analysis.

05

API Deployment & Inference

The winning pipeline is serialized to .joblib and served via Flask. The POST /api/predict endpoint validates 9 inputs, runs inference, and returns the status + approval score.
